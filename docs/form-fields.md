## Peachhacks Registration From

Pre-Registration Form: Capture the initial interest of your hackers. Getting their name, email and some social channels is a great starting point to send outreach once registrations have opened up. If you plan on working with MLH, including our required fields will speed up the Member Event onboarding process.

Reference: [MLH Guide - Registrations](https://guide.mlh.com/general-information/managing-registrations/registrations)

### Recommended Pre-Registration Fields

- Name
- Email

### MLH Required Fields (for full Member Event registration)

These aren't required for pre-registration, but including them now speeds up MLH Member Event onboarding later:

- First Name (collected separately from Last Name)
- Last Name (collected separately from First Name)
- Age (dropdown with specific ages, not date of birth)
- Phone Number
- Email
- School (use a set/searchable list instead of free text)
- Level of Study (secondary/high school through post-doctorate)
- Country of Residence (dropdown using the ISO 3166 standard)

### MLH Required Checkboxes (3 total)

Two mandatory agreements:
1. Code of Conduct acceptance
2. Authorization to share registration data with MLH and DEV for event administration and linked account creation

One optional checkbox:
- Authorization for MLH + DEV to send occasional emails about events and opportunities

### Optional Fields

- Dietary restrictions
- Gender identity
- Pronouns
- Race/ethnicity
- Sexual orientation
- Education level
- T-shirt size
- Shipping address
- Major/field of study
- LinkedIn URL
